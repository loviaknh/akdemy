Académie d'Art et de Scène - Site Web


📋 Vue d'ensemble

Ce dépôt contient le code source du site web de l'Académie d'Art et de Scène, une institution dédiée à l'enseignement des arts du spectacle, de la musique et de la danse dans une ville nommé Cotonou, Bénin.

✨ Caractéristiques

- Design responsive adapté à tous les appareils
- Navigation intuitive avec menu hamburger pour mobile
- Sections bien définies présentant les cours, événements et témoignages
- Formulaire de contact pour les inscriptions et demandes de renseignements
- Effets visuels élégants et animations pour une expérience utilisateur améliorée

🚀 Structure du projet

```
academie-art-scene/
│
├── index.html               Page d'accueil principale
├── formulaire.html          Page de formulaire de contact
├── style.css                Feuille de style principale
├── script.js                JavaScript pour les interactions
└── image/                   Dossier contenant les images
    └── logo.png             Logo de l'académie
```

🎨 Palette de couleurs

Le site utilise une palette de couleurs chaleureuse et élégante :

- Cacao clair (`#f5e7d3`) : Fond pour les sections importantes
- Jaune (`#ffd54f`) : Boutons et accents
- Blanc (`#ffffff`) : Fond général et cartes
- Texte (`#333333`) : Texte principal et pied de page

🛠️ Technologies utilisées

- HTML5
- CSS3 (avec variables CSS pour la palette de couleurs)
- JavaScript vanilla pour les interactions
- Font Awesome pour les icônes
- Polices : Segoe UI, Tahoma, Geneva, Verdana, sans-serif

📱 Fonctionnalités responsive

- Menu hamburger pour appareils mobiles
- Mise en page flexible avec Flexbox
- Images et contenus redimensionnables
- Sliders tactiles pour la navigation mobile

🖥️ Aperçu des sections

1. Hero - Accueil avec appel à l'action
2. Mission - Présentation de la philosophie de l'académie
3. Valeurs et Enseignants - Slider présentant les fondamentaux
4. Cours - Présentation des différents cours proposés
5. Événements - Calendrier des événements à venir
6. Témoignages - Retours d'expérience des élèves
7. Contact - Informations de contact et liens sociaux

💡 Fonctionnalités JavaScript

- Navigation responsive avec menu hamburger
- Slider pour alterner entre "Nos Valeurs" et "Nos Enseignants"
- Lazy loading des images pour optimiser les performances
- Animations au scroll pour une meilleure expérience utilisateur
